# Twitter Clone

A basic Twitter clone built using HTML, CSS, and vanilla JavaScript. This project focuses on core social feed interactions such as tweeting, liking, retweeting, commenting, and deleting posts.

## Features

- Create a tweet
- Like a tweet
- Retweet a post
- Comment on a tweet
- Delete a tweet

## Project Type

This is a front-end only project built for practice and learning purposes. The app currently uses example/mock data, and a database is not connected yet.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Purpose

The goal of this project was to practice DOM manipulation, event handling, and building interactive UI features using only core web technologies without any frameworks or libraries.

## Notes

- This is a basic clone of Twitter/X with limited functionality
- Data is not stored permanently
- The feed is rendered using example data for demonstration
